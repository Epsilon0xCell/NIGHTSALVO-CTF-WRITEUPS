Crypto

shufflebox

DownUnderCTF 2024, beginner

A fixed 16 character permutation shuffles every block. Two known plaintext pairs recover the permutation outright, and inverting it unshuffles the censored line.

Sun Zi's Perfect Math Class

DownUnderCTF 2024, beginner

One RSA message encrypted with e = 3 under three different moduli. CRT recombines the ciphertexts into m cubed over the integers: Hastad's broadcast attack, finished with an exact cube root.

V for Vieta

DownUnderCTF 2024, easy

An interactive server demands huge solutions to (a^2 + ab + b^2) / (2ab + 1) = k. Vieta jumping climbs from the seed (0, sqrt(k)) until both values clear 2048 bits.

three-line-crypto

DownUnderCTF 2024

A 16-byte key selected by the previous plaintext byte protects 5,611 bytes of prose. A trigram model and a hot simulated annealing run recover the key after colder searches stall.

baby-arx

DownUnderCTF 2022, beginner

Two rotate-xor byte maps feed adjacent flag bytes into each output. Walking the chain from the known prefix and following the two possible preimages at each step recovers the full state.

rot-i

DownUnderCTF 2020, beginner

Each letter shifts by its position in the whole message, counting spaces and punctuation. Reversing that position-dependent shift inside the matching case alphabet restores the text directly.

babyrsa

DownUnderCTF 2020, medium

An extra RSA value is the modular inverse of 557p - 127q. Recovering that linear relation turns factoring the modulus into solving one quadratic.

Hex Shift Cipher

DownUnderCTF 2020, medium

Forty-four known plaintext characters turn a shuffled hex cipher into a linear system over GF(2). The permutation requirement narrows the key completions, and every valid one gives the same plaintext.

H1

Google CTF 2021

Repeated-byte ECDSA nonces shrink a 512-bit ECDH exchange to a hidden number problem. Recovering the signing key and public key exposes the shared secret and the encrypted flag message.

Substitution Cipher I

DownUnderCTF 2021, beginner

A quadratic polynomial substitutes for a cipher table. Because it is one-to-one over byte values, solving the quadratic inverts each output character.

Complementary

DownUnderCTF 2023, beginner

The two flag halves are multiplied as integers, but their ASCII structure gives the product an unusually rich factorization. Searching the factor splits finds the one framed by the flag format.

Randomly Chosen

DownUnderCTF 2023, beginner

Only 1,337 possible inner seeds drive 305 sampled characters. Replaying each seed and rejecting inconsistent positions leaves exactly one seed and the full flag.

apbq RSA I

DownUnderCTF 2023

Two hints of the form a p + b q conceal the factors of an RSA modulus. Combining the hints cancels p, and a batch gcd search over the small a values finds q.

Very Hot

LA CTF 2024

Three RSA primes sit at p, p + 6, and p + 12, putting the modulus near a perfect cube. A short scan around its integer cube root finds p and the other factors follow from their offsets.

Selamat Pagi

LA CTF 2024

The challenge title is itself a crib for an Indonesian substitution cipher. The flag format and word patterns then resolve each remaining word without recovering the whole key.

Naptime

UIUCTF 2024

A Merkle-Hellman knapsack uses only eight public weights per character. Enumerating all 256 subset sums with the generator bit convention decodes each byte directly.

Web

Parrot the Emu

DownUnderCTF 2024, beginner

A Flask parrot passes user input straight into render_template_string. One SSTI payload through a Jinja2 global reads the flag file off the server.

Forensics

Baby's First Forensics

DownUnderCTF 2024, beginner

A packet capture of a scan in progress. The scanner signs its own work: the User-Agent in every request names the tool and its version.

Macro Magic

DownUnderCTF 2024, easy

A spreadsheet macro XORs the value in cell A1 with the key MonkeyMagic and sends the result as decimal bytes in a web request. Static analysis identifies the matching capture run and reverses it without executing the macro.

Retro

DownUnderCTF 2021, easy

The event logo pixels carry no payload. The flag sits in plain text in the image XMP metadata, inside the Dublin Core creator field.

The Conspiracy

corCTF 2024

A small capture carries paired lists of products and keys in TCP payloads. Dividing each pair element by element turns the chat back into readable text.

Reversing

jmp flag

DownUnderCTF 2024, easy

A stripped binary runs each input character through a handler that conditionally flips one bit of a state word. Model the machine, then search for the 64 moves that clear every bit.

sssshhhh

DownUnderCTF 2024, beginner

A Go SSH server with a hardcoded password and a hidden command. Authenticate, run the command, and the server prints the flag from its own environment.

ezpz rev

DownUnderCTF 2022, easy

A stripped ELF hides a Star Battle puzzle defined by four validators and an embedded region map. A backtracking solver finds the grid, and the unmodified binary prints the flag.

Beginner

Google CTF 2020, beginner

The binary compares its input with that same input after a shuffle, add, and xor transform. Treating the flag as a fixed point and solving the extracted constants with Z3 produces the accepted string.

Pwn

vector overflow

DownUnderCTF 2024, beginner

An unbounded read sits right before a std::vector. Overflow the buffer, aim the vector's pointers back into the input itself, and the element check reads the winning string out of your own payload.

Misc / OSINT

Intercepted Transmissions

DownUnderCTF 2024, beginner

A 441 bit CCIR476 transmission. The constant 4 of 7 mark ratio confirms the framing, and a stateful LTRS/FIGS decode, verified by re-encoding, gives up the message.

tldr please summarise

DownUnderCTF 2024, beginner

A Word document with a white on white prompt injection at 2 point type, ordering any AI that reads it to download and run a script. The solve is finding it and refusing it.

Wacky Recipe

DownUnderCTF 2024, easy

A program written in Chef with two redacted ingredient values. Each block is one arithmetic expression; solving the system against the flag wrapper gives pain = 27 and effort = 21.

DNAdecay

DownUnderCTF 2024, easy

A Ruby program is encoded as DNA art, with bases lost to decay. Exact-column parsing and complementary base pairs repair the damaged rungs, while context resolves the few positions where both bases are gone.

last digit

DownUnderCTF 2022, easy

A last-digit service becomes a comparison oracle through the Python integer conversion limit of 4,300 digits. Threshold queries and binary search recover the flag integer.

In a pickle

DownUnderCTF 2020, easy

A 397-byte file is a Python pickle holding a position map. Disassembling it instead of loading it, sorting the keys, and converting the values rebuilds the message safely.

Symatrix

Google CTF 2023

A mirrored PNG hides bits in pixels whose green channel rises by exactly one. Reading the blue channel differences at those marked spots restores the hidden bit string.

NPC

Google CTF 2023

A Hamiltonian path through a letter graph spells a password from Constitution words. The graph and word list leave only 13 candidates, and the eleventh decrypts the age-encrypted file.

Flag Art

DownUnderCTF 2023, beginner

Each byte is printed as four symbols giving its residues modulo 2, 3, 5, and 7. The Chinese Remainder Theorem turns each group of symbols back into the exact character.
